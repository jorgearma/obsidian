# ⚡ Ubuntu Shortcuts para Productividad (Nivel Dev Pro)

Guía rápida para moverte con fluidez, parecer eficiente en entrevistas y trabajar sin perder tiempo.

---

## 🧭 Navegación entre apps

- `Alt + Tab` → Cambiar entre aplicaciones  
- `Alt + Shift + Tab` → Cambiar hacia atrás  
- `Alt + ~` → Cambiar entre ventanas de la misma app  
- `Super + Tab` → Vista general de apps  

💡 **Tip pro:** usa `Alt + ~` cuando tengas muchas ventanas de VSCode / navegador.

---

## 🖥️ Gestión de ventanas

- `Super + ↑` → Maximizar  
- `Super + ↓` → Restaurar / minimizar  
- `Super + ← / →` → Ajustar ventana a lado (split screen)  
- `Alt + F4` → Cerrar ventana  
- `Alt + Space` → Menú de ventana (mover, redimensionar)

💡 **Workflow pro:**  
Código izquierda + navegador derecha (`Super + ← / →`)

---

## 🚀 Lanzar apps rápido

- `Super` → Buscar apps (lo más usado)  
- `Alt + F2` → Ejecutar comando (`gnome-terminal`, etc.)  
- `Ctrl + Alt + T` → Abrir terminal  

💡 **Tip entrevista:** usa `Super` y escribe rápido → demuestra fluidez.

---

## 🧱 Workspaces (multi-escritorios)

- `Ctrl + Alt + ↑ / ↓` → Cambiar workspace  
- `Shift + Ctrl + Alt + ↑ / ↓` → Mover ventana  

💡 **Setup recomendado:**
- WS1 → Código  
- WS2 → Navegador  
- WS3 → Terminal / logs  

Esto impresiona mucho en entrevistas.

---

## 📸 Sistema y utilidades

- `Super + L` → Bloquear pantalla  
- `PrtSc` → Screenshot completo  
- `Shift + PrtSc` → Selección de área  
- `Ctrl + Q` → Cerrar app  

---

# 🧠 Nivel PRO (menos conocidos pero MUY útiles)

## 🔥 Control fino de ventanas

- `Alt + F7` → Mover ventana con teclado  
- `Alt + F8` → Redimensionar ventana  
- `Super + H` → Ocultar ventana  
- `Ctrl + Super + ← / →` → Mover ventana entre monitores  

---

## ⚡ Productividad extrema

- `Ctrl + Alt + D` → Mostrar escritorio  
- `Super + D` → Alternativa (según config)  
- `Ctrl + Alt + L` → Bloquear sesión (alternativa)  

---

## 🖥️ Terminal / sistema profundo

- `Ctrl + Alt + F3` → Ir a consola TTY (modo hacker real)  
- `Ctrl + Alt + F2` → Volver al entorno gráfico  
- `Ctrl + Shift + Esc` → Monitor sistema (según config)  

💡 **Esto demuestra nivel técnico real si sabes usarlo.**

---

## 🧩 Gestión rápida de archivos

- `Ctrl + L` (en explorador) → Ir a ruta manual  
- `Ctrl + H` → Mostrar archivos ocultos  
- `Alt + Enter` → Propiedades archivo  

---

## 🧠 Hacks mentales (clave para entrevistas)

✔ No uses ratón para abrir apps → usa `Super`  
✔ Divide pantalla constantemente  
✔ Usa workspaces sin pensar  
✔ Cambia entre ventanas sin mirar teclado  
✔ Terminal siempre accesible (`Ctrl + Alt + T`)
